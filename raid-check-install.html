Raid Check

Checks a Warcraft Logs report for world buffs, consumes and enchants. Runs in your browser on vanilla.warcraftlogs.com, so no API key or login is needed.

Option 1: bookmarklet (easiest)

  1. Show your bookmarks bar (Ctrl+Shift+B, or Cmd+Shift+B on Mac).
  2. Drag this button onto the bookmarks bar:  Raid Check
  3. Open any report on vanilla.warcraftlogs.com and click the bookmark.
  4. A panel opens with that report filled in. Add more report links (one per line) to combine logs from the same night, such as MC + BWL, and press Run.

Option 2: paste into the console

  1. Open a report on vanilla.warcraftlogs.com.
  2. Press F12, open the Console tab, paste the code below and press Enter. (Chrome may ask you to type allow pasting first.)

What it checks

World buffs. The rule is passed with 2 world buffs and a flask, or with 3 or more world buffs. The counted buffs are Ony/Nef, Rend, ZG, Songflower, Dire Maul and Darkmoon Faire. The three Dire Maul buffs count as 1. A buff counts if the player had it at any point in the log.

Consumes. Flasks, elixirs, Zanza, Juju and Blasted Lands buffs, food, alcohol, protection potions, Free Action and weapon oils or stones are all counted. Rogue poisons are not.

Enchants. Chest, feet, wrist, hands, back and main hand must be enchanted. So must the off hand if it's a weapon or shield, and the ranged slot for hunters. Head, shoulders and legs are skipped. Only whether an enchant exists is checked, not which one. Gear is read from the boss pulls.

Everything is configurable in the settings block at the top of the code. To change it for the bookmarklet, edit the code and make a new bookmark whose URL is javascript: followed by the code.
